## 一、系统概览

本系统是赛特智能的机器人运维管理平台，用于管理全国数百个项目的机器人设备监控、告警处理、工单流转、巡检调度等运维工作。

## 四、关键业务流程

### 告警处理流程
```
设备告警 → 告警列表（查看详情）
         → 告警管理（临时关停/配置规则）
         → 工单管理（创建工单 → 分派 → 处理 → 关闭）
```

### 设备监控流程
```
运维工作台（发现异常项目）
  → 机器人监控（选择项目+设备 → 查看运行/硬件状态）
  → 查看截图/日志/视频
  → 开启远控（远程操作）
```

### 巡检流程
```
巡检管理 → 新建巡检任务
        → 设置巡检人员、日期、时段、间隔
        → 启用/禁用任务
        → 查看巡检结果
```
