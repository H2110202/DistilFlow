# 工单与第三方字段模板数据整合分析

## 触发条件
用户上传包含工单数据及第三方字段模板的Excel文件（例如“工单及第三方字段模板.xlsx”），并要求对数据进行读取、统计、清洗、转换或合并等复杂处理。

## 执行步骤
1. 使用 `list_files` 确认上传的Excel文件存在。  
2. 使用 `read_excel` 依次读取文件中的各个Sheet（如工单主表、第三方字段明细、字典表等），获取原始数据。  
3. 使用 `excel_stats` 对每个Sheet进行基础统计（行数、列数、缺失值、数据类型等），了解数据概貌。  
4. 根据业务需求，使用 `execute_code` 编写Python脚本进行数据清洗（如去重、填充缺失值、格式统一）、字段映射（将工单字段与第三方字段模板关联）、计算衍生指标（如时长、得分）或合并多表。  
5. 重复步骤2–4，按需读取中间结果或追加处理（例如先清洗工单数据，再读取模板进行匹配）。  
6. 最终通过 `read_excel` 或 `execute_code` 输出整合后的结果（如保存为新Excel文件或返回数据摘要）。

## 注意事项
- 确保Excel文件包含所有预期的Sheet，且列名、数据类型与后续代码逻辑一致。  
- 多次 `execute_code` 时需注意变量作用域和依赖顺序，避免重复加载或状态污染。  
- 处理大量数据时注意性能，可分批读取或使用 Pandas 的向量化操作。  
- 若存在敏感字段（如工单ID、用户信息），执行代码前应确认数据脱敏或权限。  
- 最终结果建议输出为独立Excel文件，便于用户下载或后续使用。
