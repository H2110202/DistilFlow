# 双数据源独立匹配对照表模板生成报表

## 触发条件
用户提供一份已清洗的对照表（模板），以及两个独立的数据源表（工单表和第三方申请单表），要求将两个数据源分别匹配到对照表模板中，生成两个独立的输出表格。

## 执行步骤
1. 调用 `list_files` 列出工作目录下所有文件，识别所需的对照表、工单表和第三方申请单表（建议文件名中包含“对照表”、“工单”、“第三方申请单”等关键词）。
2. 使用 `read_excel` 读取对照表模板，获取其表头结构和格式。
3. 使用 `read_excel` 读取工单数据表。
4. 使用 `read_excel` 读取第三方申请单数据表。
5. 调用 `excel_stats` 分别检查工单表和第三方申请单表的基本统计信息（如行数、列数、缺失值等），确保数据完整。
6. 使用 `read_excel` 再次读取对照表（或存储其副本），作为工单输出模板。
7. 使用 `read_excel` 读取工单数据（或直接从步骤3的结果中提取），按照对照表模板的列结构进行匹配（例如通过共同字段如“工单编号”或“申请单号”进行左连接），将工单数据填入模板，生成工单输出表。
8. 使用 `read_excel` 读取第三方申请单数据（或直接从步骤4的结果中提取），按照相同对照表模板的列结构进行独立匹配（不关联工单数据），生成第三方申请单输出表。
9. 将两个输出表分别保存为独立的Excel文件（例如“工单_已清洗对照表.xlsx”和“第三方申请单_已清洗对照表.xlsx”），格式与上传的对照表完全一致。

## 注意事项
- 工单表和第三方申请单表之间无需进行任何关联或合并，各自独立匹配到对照表模板即可。
- 对照表模板中的列名必须唯一且与数据源中的对应列名一致（或可通过映射关系转换），否则匹配会失败。
- 若数据源中存在对照表模板中不存在的列，应忽略；若缺少必要的列，需提前报错或填充空值。
- 建议在匹配前对数据源进行去重、空值处理等基本清洗，避免后续输出表出现重复行或错误。
- 最终输出的两个表格应保持与上传的已清洗对照表完全相同的行列顺序、单元格格式和样式（如合并单元格、字体、边框等）。
